# Чем Яндекс отличается от Google (практические правила)

## robots.txt
- **Группа `User-agent: Yandex` полностью заменяет `User-agent: *` для Яндекса.** Правила не суммируются.
  Добавляя Disallow, добавляй во все группы, которые читает целевой робот.
- `Clean-param: utm_source&utm_medium&utm_campaign /` - склеивает URL с незначащими параметрами
  (метки, сортировки, сессии). Google директиву не знает - там canonical.
- `Host:` - устарел, игнорируется; главное зеркало задаётся 301-редиректом (и видно в Вебмастере как `main_mirror`).
- `Crawl-delay` игнорируется; скорость обхода регулируется в Вебмастере.
- Disallow не убирает страницу из индекса мгновенно; для удаления - `noindex` (страница должна быть открыта
  в robots, иначе робот не увидит мета-тег).

## Индексация
- **Зеркала:** сайты с одинаковым содержимым или связанные редиректом Яндекс склеивает; неглавное зеркало
  не ранжируется. Расклейка: убрать редиректы между ними, сделать содержимое разным, «Разгруппировка
  адресов» в Вебмастере неглавного адреса; занимает до ~2 недель.
- Переобход: Вебмастер → «Переобход страниц» (квота в сутки, видна в API `recrawl/quota`) и IndexNow
  (`api.indexnow.org` передаёт и Яндексу). Обход по счётчику Метрики включается в настройках счётчика
  (диагностика `NO_METRIKA_COUNTER_CRAWL_ENABLED`).
- Яндекс индексирует преимущественно мобильным роботом; если у сайта отдельный мобильный шаблон
  (Битрикс/Аспро часто), каждую правку проверяй и в нём.
- `rel=canonical` между разными хостами (поддоменами) Яндекс может не принять - это разные сайты.

## Ранжирование
- **Регион** решает для геозависимых запросов («купить», «доставка», услуги). Сайт без региона
  проигрывает региональным конкурентам. Регион даёт Вебмастер (вручную) и Яндекс.Бизнес.
- **ИКС** (индекс качества сайта) - агрегат популярности и удовлетворённости, не фактор напрямую,
  но хороший индикатор. Падение ИКС после склейки/фильтра - сигнал.
- **Коммерческие факторы** (важнее, чем в Google): ассортимент, цены на видных местах, способы
  доставки и оплаты, контакты и реквизиты, телефон с кодом города, условия возврата, отзывы.
- **Поведенческие факторы**: возвраты в выдачу, глубина, время. Накрутка ПФ → фильтр; не советовать.
- Тексты: переспам ключей → фильтр «Баден-Баден»; покупные ссылки → «Минусинск».

## Метрика
- Поисковые фразы Яндекса в основном скрыты (`(not set)`); запросы - из Вебмастера.
- Атрибуция по умолчанию в отчётах API - «автоматическая»; для сравнения с интерфейсом указывай явно.
- Поддомены считаются одним счётчиком, если добавлены как дополнительные адреса; разбивка - `ym:s:startURLDomain`.

## Вордстат
- Частота = показы за 30 дней, все словоформы и хвосты. Точная форма: `"!купить !бензопилу"`.
- Регион обязателен для локального бизнеса: спрос «бензопила» в Москве и Новосибирске отличается по структуре.
